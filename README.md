# Практическая работа № 10. Docker Compose

Андрей Бромбин, группа МПрВИС21.

Nginx принимает HTTPS-запросы на `https://localhost/` и по очереди передаёт их двум Flask-приложениям. При обновлении страницы в приветствии меняется имя приложения — `app1` или `app2`.

[Отчёт с разбором ошибок и скриншотами](REPORT.md) · [Подробный отчёт в PDF](report.pdf)

## Запуск

Из корня репозитория выполните команду:

```sh
docker compose up --build -d --wait
```

Откройте `https://localhost/`, подтвердите переход с локальным самоподписанным сертификатом и обновите страницу. Для запуска нужен свободный порт 443.

Чтобы остановить стенд, выполните `docker compose down`.
